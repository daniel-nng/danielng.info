**Who Was It For?** Me, and anyone who wants to know more about me.

**What Was It?** My personal site, which started out as hand-written HTML pages uploaded to S3. I rebuilt it so it's easier to update and safer to change.

**What Did I Do?**

- Ported the site to Astro, with a shared layout and components in place of copy-pasted HTML.
- Added smoke, link, and visual regression tests with Playwright.
- Set up GitHub Actions to deploy to a dev site for QA, then to production on S3 and CloudFront after approval.
- Fixed the mobile layout and added favicons, robots.txt, and a traffic report built from the CloudFront logs.

**Can I See It?** You're looking at it! The code is on [GitHub](https://github.com/daniel-nng/danielng.info).
